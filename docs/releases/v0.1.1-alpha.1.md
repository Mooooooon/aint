# AINT v0.1.1-alpha.1 · 游玩设置与模型选择更新

本预览版更新游玩设置与模型选择交互，并修复自动补选项时的旁白显示。

## 本次更新

- 游玩中的模型与预算面板支持自动保存：点击外部、再次点击入口或按 Esc 收起时保存，下一回合生效。取消确认会撤销本次修改并关闭面板；输入无效或保存失败时保留草稿。
- 点击模型名称打开按供应商分组的模型列表，进入列表与返回时增加过渡动画。
- 推理强度显示在滑条上方，滑条支持平滑拖动，圆钮在悬停时轻微放大。
- 模型切换与高预算确认增加“不再提示”，分别记忆选择，所有存档和连接同一服务的浏览器共用。
- 发送输入或选择剧情选项前等待设置保存，避免配置尚未生效就发起回合及重复提交。
- 删除上下文设置中重复的翻阅资料提示开关，统一保留在“阅读与外观”。
- 移除常驻提示词中每回合必须生成选项的要求。作品开启 `force_choices` 后，正文结束且缺少选项时自动补充；补选项阶段的普通文字不进入正文和后续故事历史。
- 两部内置作品名称增加“（示例）”，简介顶部说明 skill 生成示例与最小作品示例的用途；调整封面题签，保持加长后的书名单列显示。

## 更新与下载

在[发布页](https://github.com/wahhheee/aint/releases/tag/v0.1.1-alpha.1)下载对应系统与处理器的压缩包。常见 Intel / AMD Windows 电脑选择 `aint_0.1.1-alpha.1_windows_amd64.zip`；其他平台选择对应的 `windows_arm64`、`darwin` 或 `linux` 包。

更新前停止程序并备份数据目录，替换可执行文件，保留原数据目录与启动参数。
